# ONNX Model Zoo MNIST

The `artifacts/model.onnx` file is the pretrained `mnist-8` model from the
ONNX Model Zoo. Its model-specific upstream README identifies the model as MIT
licensed.

- Upstream: https://github.com/onnx/models/tree/main/validated/vision/classification/mnist
- Pinned mirror: https://huggingface.co/onnxmodelzoo/mnist-8/tree/a19f9a8c2333de1df9b03f10f5739f468b699a1a
